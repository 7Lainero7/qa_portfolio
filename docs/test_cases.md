# Тест-кейсы: API создания расхода

| ID | Название | Предусловие | Шаги | Ожидаемый результат | Приоритет |
|----|----------|-------------|------|---------------------|-----------|
| TC-01 | Успешное создание расхода | Пользователь имеет валидный `X-API-Key` | 1. Отправить POST `/api/expenses` с валидным JSON (title, amount_cents, category). | Статус 201 Created. В ответе возвращаются `id`, `title`, `amount_cents`, `category="food"`, `created_at`. | High |
| TC-02 | Создание расхода без категории | Пользователь имеет валидный `X-API-Key` | 1. Отправить POST `/api/expenses` без поля `category`. | Статус 201 Created. В ответе `category="other"` (значение по умолчанию). | Medium |
| TC-03 | Создание расхода с отрицательной суммой | Пользователь имеет валидный `X-API-Key` | 1. Отправить POST `/api/expenses` с `amount_cents: -100`. | Статус 422 Unprocessable Entity. Ошибка валидации Pydantic. | High |
| TC-04 | Создание расхода без API-ключа | Отсутствует | 1. Отправить POST `/api/expenses` без заголовка `X-API-Key`. | Статус 401 Unauthorized. | High |
